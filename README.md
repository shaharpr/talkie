# Talkie - a multi-purpose interactive chatbot
*This README file is translated from Hebrew by Google Translate*

## Introduction
Talkie is a multi-purpose interactive chatbot based on GPT-3.5 (ChatGPT).

Language models are unable to search the Internet, tell the time, or even do complicated calculations.

Using a backend (a software component that is not a language model that can do what the model cannot do, and that can communicate with the model) can help language models be more "interactive" and formulate more accurate answers.

Talkie is an implementation of such a language model with a backend, which produces very promising results. Any message sent to Talkie, Talkie can choose to send a command to the backend, prefixed with '#', receive a reply from the backend, and formulate the final answer according to the result of the commands it sent.

## Features
The current implementation of Talkie can:
* **Chat** like a normal chatbot
* **Calculate** equations with a calculator backend
* Check **What time is it** with a clock backend

## Installation
You can download the distribution ZIP file of Talkie from [here](https://github.com/shaharpr/talkie/releases),

*OR* you can build it yourself using:

```bash
git clone https://github.com/shaharpr/talkie.git
cd talkie
mvn clean package
```

Extract the ZIP file to wherever you want.

## Usage
Talkie has three parts.

1. **Server** - The server contains Talkie's own code (the model and the backend), and Talkie's API.
2. **Console client** - minimal client software that runs from the command line.
3. **Telegram bot** - a Telegram bot that is connected to Talkie's server (later we will merge the server and the bot)

The server relies on the OpenAI API, so you need to create an API key [here](https://platform.openai.com/account/api-keys). To run the Telegram bot, you need to talk
to [@BotFather](https://t.me/BotFather) to create a bot.

Set the environment variables:

```
OPENAI_API_KEY - Your OpenAI API Key
TALKIE_BOT_TOKEN - The token of your bot
```

To run the server, start `talkie_server.bat`.

You can run the client (`talkie_client.bat`) or the Telegram bot (`talkie_telegramBot.bat`) and start a new conversation.

Enjoy! 😀

## Talkie API
Talkie has an HTTP API for building clients.
Types:
* **Message** - A string, enclosed in quotes, that represents a message to/from Talkie
* **Conversation ID** - A quoted string that represents a call ID. Each call the server generates a call ID for multiple calls. The call ID is generated by this formula: SHA256(key) + "-" + random(0,255)
* **API key** - API key used by the server to send requests to the OpenAI API.

Endpoints:

GET /new - Create a new conversation
> Headers:
>> x-api-key - The OpenAI API Key for the server

> Returns:
>> a Conversation ID

POST /talkie/{id} - Send a message to Talkie, conversation ID {id}
> Headers:
>> x-api-key - The OpenAI API Key for the server

> Body: a Message

> Returns: a Message - Talkie's response to the message

DELETE /talkie/{id} - Delete conversation {id}
> Headers:
>> x-api-key - The OpenAI API Key for the server
